# Yakumo API Docs

This directory keeps the long-lived project documents that remain useful after the current delivery phase.

## Documents

- [feature-status.md](feature-status.md): current desktop app and `yaku` CLI capability matrix.
- [desktop-smoke.md](desktop-smoke.md): manual desktop release smoke checklist.
- [macos-damaged-app.md](macos-damaged-app.md): workaround for unsigned macOS test builds blocked by Gatekeeper.
- [notice.md](notice.md): project origin, license inheritance, and attribution notes.

## Scope

Roadmaps and one-off implementation tracking notes are intentionally not kept here once the work is complete. Keep this directory focused on operator-facing and maintainer-facing reference material.
